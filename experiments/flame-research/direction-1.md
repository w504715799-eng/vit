# 方向一：冻结 DINOv3 的少样本跨场景火焰分割

> **2026-10-07 审计：有条件保留，尚不可执行。** [复核报告](review-2026-10-07.md)指出创新重叠、遗漏 INSID3、校准成本和功效问题。下文保留 v1 候选与门槛供修改，不代表通过开跑审查。

## 研究问题与可证伪假设

在少量带掩码支持图像下，基础视觉特征容易把灯光、反光和暖色物体当火焰。假设：从支持图像背景中挑选与火焰最相似的背景特征作为对照，能够提升外部场景的火焰分割，同时不增加无火图像的误检面积。

2026 锚点是 [FSSDINO](https://arxiv.org/abs/2602.07550) 对冻结 DINOv3 少样本分割的研究。DINOv3 本身于 2025 年发布；不能称为 2026 年新模型，也不能把“用于火焰”直接当创新。困难背景原型已有广泛研究，本轮只检验其是否构成值得深入的火焰跨域问题。前置查新不能找到明确差异，则不运行。

## 固定数据角色

| 数据 | 角色 | 最低要求 |
| --- | --- | --- |
| Khan Fire_Seg_Dataset | 唯一支持来源和源域校准 | 至少 15 个独立火焰图像组，每种子取 5 个不同组、每组 1 图；另有 ≥30 个不重叠火焰校准组 |
| DFire 的 D1 专用分区 | 源域无火校准 | ≥60 个独立无火组；没有 fire 框才算无火，smoke-only 可为无可见火焰 |
| BoWFire | 主外部目标域 | 去重后初筛与确认各 ≥30 火焰组、≥30 无火组 |
| FLAME 有掩码部分 | 预先固定的辅助外部诊断 | 最多 100 张、按视频/事件均匀选；不用于主通过判定或支持集 |

BoWFire 用于补足无火场景和独立照片评价；原研究报告 226 张图像（119 火、107 无火），可用独立组数必须下载后核实。按组/类别，以固定种子大致 1:1 划分初筛和确认；样本数量不足即失败，不能挑选效果更好的子集。Khan 的独立来源与许可证、FLAME 具体掩码下载均需前置核实。

标签仅为可见火焰；烟雾不算火焰。DFire 的框不能当像素掩码。禁止从 FLAME 相邻帧随机拆出训练/测试以获得虚高指标。

## v1 唯一候选与三个基线（需补入 INSID3 后重新冻结）

共同设置：官方 DINOv3 ViT-B/16 冻结权重，最后一层 patch 特征，去掉特殊 token；RGB 等比例缩放后补边到 512×512，补边不参与指标。patch 特征 L2 归一化；最终概率双线性插值回原图。禁止逐层搜索、测试时训练和解码器微调。

支持 mask 下采样为 patch 占比，≥0.8 为前景、≤0.2 为背景，中间 patch 丢弃。每类按固定种子最多均匀取 10,000 个 patch；同一支持抽样用于所有方法。

- B1：前景、背景各一个均值原型。
- B2：前景、背景各 K=3 个球面 k-means 原型，初始化种子随支持种子固定，最多 50 次迭代、单次初始化；这是排除“仅原型变多”解释的关键基线。
- B3：官方 FSSDINO 最后一层 + Gram refinement，固定作者默认设置，适配同一骨干、支持和输入；不得使用 oracle 层选择。开跑前记录实际配置及 commit。已核实实际配置路径为 configs/dg.yaml，其 n_clusters=5；此前把路径读取失败视为配置缺失不准确。须固定具体配置，不能只写“作者默认”。尚未运行复现。
- C（唯一候选）：在 B2 上仅改变背景原型来源。对支持背景 patch 计算其与任一前景原型的最大余弦相似度，选得分最高的 25% 做 K=3 背景聚类；前景原型保持 B2 不变。

B1、B2、C 的像素概率 p = sigmoid((最高前景余弦相似度 − 最高背景余弦相似度)/0.07)。B3 官方返回类别 mask 和最大类别分数，后者不是前景概率，禁止直接套用下述网格。B3 原生输出需单列；若增加 fire/background margin 校准适配版，必须命名、定义、检查后重新冻结协议。B1、B2、C 的 v1 校准草案是只在源域校准集合上一次性从预定阈值网格 {0.05,0.10,…,0.95} 中，选无火预测面积宏平均 ≤1% 时火焰 IoU 最高的阈值；并列取更高阈值，无可行阈值则该方法记不可行，关键基线不可行导致方向失败。这是固定的源域校准规则，不是目标域调参。

这里的 5-shot 仅指每次支持集；还使用 ≥30 张有火校准 mask 和 ≥60 张无火标签，必须报告额外监督成本，不能声称总标注量只有五张。

必须补入 [INSID3 官方实现](https://github.com/visinf/INSID3)作为直接强基线；其骨干/分辨率、原生版与受控适配版、评价工作点仍待固定，未固定不得开跑。旧门槛中的“三个基线”仅记录 v1，不是最终基线清单。

三个支持种子是预定重复测量，不是三个候选方法。B1/B2/C 共享缓存；B3 若不能复用，耗时仍计预算。

## 最小检验与通过门槛

主指标：有火组的前景 IoU 宏平均（不加入背景 IoU）；无火指标：预测为火焰的像素占有效像素比例，按组宏平均。另记录前景像素召回、Dice、每图耗时和显存。

初筛全部满足才开确认集：

1. C 的前景 IoU ≥0.60。
2. C 相比三个基线中最佳前景 IoU，至少增加 0.03（3 个百分点）。
3. C 的无火预测面积 ≤1%，且相对每个基线的增加均 ≤0.001（0.1 个百分点）。
4. C 的火焰像素召回相对每个基线下降均不超过 0.01。
5. 三个支持种子的 C−B2 IoU 差值均 >0，不能靠一次幸运支持集通过。

确认：重新满足上述全部门槛，并且“相对所有基线的最小 IoU 改善”单侧 95% 配对组 bootstrap 下界 >0。FLAME 辅助结果只描述，不得补救主评价失败；初筛通过后与确认一起跑一次。

这些门槛是严格的项目止损标准；未达标不证明 DINOv3 或该问题在更大预算下没有价值。

## 四工作日步骤

1. D1：核实独立样本/许可证、最接近方法和官方配置；冻结清单。先在非评价样本测吞吐。
2. D2：实现数据适配与 B1/B2/B3/C；用合成 mask 检查坐标和 IoU，缓存特征并记录 SHA-256。
3. D3：一次性运行所有初筛配置，生成同组配对表；任一门槛失败立刻结束 D1，切换 D2。
4. D4：只有初筛通过才运行锁定确认和 FLAME 辅助集；通过则收工整理，不通过则切换 D2。

输出：固定支持 ID、模型/数据版本、各基线配置、逐图指标与组 ID、三个种子结果、配对区间、失败案例和一次决策记录。禁止增加 K 值、换层、加注意力模块或提高分辨率挽救结果。
