# 方向二：用全图与局部视觉证据检验可靠火焰识别

> **2026-10-07 审计：当前乘积候选不建议作为论文主方法立项。** [FireMAS](https://doi.org/10.1016/j.firesaf.2026.104648)已有相关全局/局部火灾验证研究，g×l 也不是一致性度量。详见[复核报告](review-2026-10-07.md)。以下仅保留 v1 草案，不可自动启动为备选实验。

本方向只在方向一失败后启动，是唯一一次换方向机会。

## 研究问题

同一个冻结视觉语言模型对“全图有火”和“局部确实有火”的判断是否一致？这种一致性是否能在保持火焰召回的前提下减少误报，而不仅仅是把报警阈值抬高？

2026 锚点是 [SAFIRE](https://arxiv.org/abs/2609.07823) 所提出的火烟理解可靠性问题。采用旧而较小的开放模型控制成本；不把模型版本包装为新颖性。全局/局部融合和分数相乘本身都不是已证实的新贡献，本轮检验的是跨场景可靠性假设。若前置查新显示同问题同评价已有充分结果，判失败，不临时转成“大模型微调”。

## 固定模型、数据与任务

- 模型：官方 Qwen2.5-VL-3B-Instruct，冻结，BF16，不量化，不 LoRA。以[官方模型卡](https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct)为加载依据，revision 开跑前锁定。
- 任务：真实照片中是否存在可见实体火焰。烟雾单独出现记负；真实蜡烛火焰记正，不把可控用火等同于“非火焰”。不是火灾危险程度分类。
- 校准：DFire 的 D2 专用分区，200 个火焰组、200 个无火组，每组 1 图。DFire 由 fire 框定义标签，不训练检测器，框格式不意味着使用 YOLO。
- 主评价：SAFIRE MCVQA 中具有明确火焰 Yes/No 标签的真实照片。仅在模型运行前根据现有标签/元数据筛选；排除图标、绘画、屏幕中的火、Not Sure/Not Applicable、标签冲突。合并同图问答。实际 schema 不含 image_id 或事件 ID；以 scenario + image_name 构造内部 ID 后核对图像哈希，不能将图片 ID 当成独立事件证明。
- 初筛：200 个正组 +200 个负组；确认：另 200 个正组 +200 个负组。优先每组 1 图，按场景/类别分层固定抽样并保证来源组不跨集合。两阶段合计至少 800 个独立组，不足就失败。
- 不把 SAFIRE 83K 用作训练集，以免其与问答图像重叠。不得宣称本子集二分类成绩等于原论文完整 MCVQA 成绩。
- 在冻结前抽取 100 个独立、非评价组核对标签；按同一任务定义人工判断，无需看模型输出。超过 5 个明显错误，或不足以确认真实照片/来源独立性，则数据门失败。此时不得反复清洗直至结果好看。

## v1 唯一候选：全局—局部乘积分数（非一致性度量）

每张图固定五次视觉输入：

1. 全图一次；
2. 四个相对宽高均为 60% 的重叠角落裁剪（左上坐标为 (0,0)、(0.4,0)、(0,0.4)、(0.4,0.4)）。

每次使用相同英文提示词：

> Is there any visible physical flame in this image? Smoke alone, lights, reflections, and orange objects are not flames. Answer Yes or No.

用 teacher forcing 读取完整“Yes”和“No”答案序列的条件对数似然，再对二者 softmax 得到 p。必须验证两答案的 token 化与终止符处理一致，记录精确定义。不使用模型自报“90% 置信度”，不对不同图片改提示词。该分数仅是两答案归一化分数，不能直接称为真实概率。

图像处理固定官方 processor，min_pixels = 256×28×28，max_pixels = 512×28×28；同一模型版本和精度用于全部视图。缓存原始两个答案 log likelihood，每图仅调用上述五视图，不多次采样。

令 g 为全图分数，l 为四个局部分数的最大值：

- B1：g（单次全图）。
- B2：l（仅裁剪聚合）。
- B3：(g+l)/2（相同五视图成本的均值融合）。
- C：g×l（v1 唯一候选，作为融合分数；不能推导为独立证据的联合概率）。

B2/B3 排除“只是多看几次图”和“任何融合都有效”的解释。这是最小机制验证；若 C 不比这些简单基线好，不加可学习门控、遮挡模块或新提示词补救。

每种方法只在 DFire 校准正样本上选择**满足经验召回 ≥95% 的最高分数阈值**；阈值固定后用于全部 SAFIRE 评价。分数相同使用 score ≥ threshold。校准不读取目标集，不在目标标签上重新做 FPR@95%TPR 阈值搜索。

## 最小判定门槛

主指标：固定源域阈值下，无火组的 FPR（误报率），同时约束火焰组 TPR（召回率）。报告各场景、全体混淆矩阵和实际延迟；平衡子集上的 precision 不能推广为实际部署 precision。

初筛须全部满足：

1. C 的 TPR ≥0.90、FPR ≤0.10。
2. C 的 TPR 相对每个基线下降均不超过 0.01。
3. C 的 FPR 相对每个基线同时降低 ≥0.05（5 个百分点）且相对降低 ≥25%。基线 FPR 为 0 时无法满足改善，判该主张没有空间，失败。
4. 候选完整五视图推理时长中位数 ≤全图单次的 6 倍，显存与总预算合格。声称的是可靠性权衡，不能声称实时性已满足。

确认：在未开封集上再次满足全部条件，并且“各基线 FPR − C 的 FPR”的最小改善单侧 95% 配对组 bootstrap 下界 >0。仅准确率提高、AUROC 提高或个别示例好看均不能替代上述判据。

200 个负组对应 1 次误报为 0.5 个百分点；5 个百分点的差值只有约 10 张图，区间可能仍较宽。这里接受严格门槛造成的提前停止，不声称已完成正式功效保证。不能见到区间跨零就临时扩样。

## 四工作日步骤

1. D1：仅在 SWITCH_TO_D2 记录存在且 switch_count=1 时开始；完成查新、标签审计、manifest、版本冻结和 20 图吞吐估计。
2. D2：实现五视图缓存、两答案序列打分与四种规则；只做合成分数/边界案例单元验证，在源域一次性校准。
3. D3：运行固定初筛，核对召回约束、误报差值与预算；失败立即 STOP。
4. D4：初筛通过才运行确认，复用同一模型、提示词和阈值；失败立即 STOP，通过则结束实验、整理报告。

输出：筛选规则、原始问题记录与由 scenario + image_name 构造的内部图像 ID 映射、去重分组、冻结阈值、五视图缓存校验和、逐图/逐组结果、四基线比较与一次最终决策。禁止换 7B/8B 模型、加入第三方向或循环修改提示词。
