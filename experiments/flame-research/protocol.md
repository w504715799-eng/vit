# 共同协议：先冻结，后计算，只切换一次

> 2026-10-07 审计补充：当前 preregistration.json 为 REQUIRES_REVISION。execution_ready=false 时不得进入 D1_PREFLIGHT 或任何模型运行状态。仅可完成[复核报告](review-2026-10-07.md)列出的文献、数据与协议问题；以下数值实验方案仍未冻结。本轮没有运行结果，因此不虚构失败或切换计数。开跑前检查不合格可直接淘汰，不强制花完两次机会。

## 1. 状态转换

允许路径只有：

- NOT_STARTED → D1_PREFLIGHT → D1_SCREEN → D1_CONFIRM → COMPLETE_D1。
- 任一 D1 关失败 → SWITCH_TO_D2（switch_count 从 0 变为 1）→ D2_PREFLIGHT → D2_SCREEN → D2_CONFIRM → COMPLETE_D2。
- 任一 D2 关失败 → STOP。
- 共用预算到顶、数据使用权限无法落实或发生全局数据泄漏 → STOP。

D1 的资源或数据特有问题算 D1 失败，可切换 D2。D2 不得再申请“换个模型试一下”。COMPLETE 和 STOP 都是本轮终态；如未来另立研究，必须由用户明确发起新协议，不能自动接着跑。

FAIL 包括：低于任一门槛、置信区间不能支持预期、样本数量或独立性不够、公开数据/权重无法在期限内获取、关键基线无法可靠实现、预算不足。INCONCLUSIVE 对投入决策按 FAIL 处理，但报告必须写“证据不足”，不能写成已证明方法无效。

## 2. 前置审计与冻结

共用审计最多 2 工作日。每方向开跑前：

1. 阅读对应 2026 论文及最接近的已有方法，登记“已有方法—当前差异—能够证伪的预测”。如果只有换骨干或拼接常见模块，且不能提出可检验的额外贡献，该方向前置失败。当前候选均是待验证假设，未完成系统性查新。
2. 确认数据和权重确实可以下载、适用许可、模型版本、标注形式。README 有链接不等于本地可用。不得为赶进度用不明镜像替代。
3. 锁定上游 Git commit、模型 revision 与权重 SHA-256、依赖版本、GPU 型号；在 preregistration.json 的 freeze 区填写真实值并提交。
4. 生成所有数据 manifest，先去重再分组划分。模型预测之前冻结源域支持集、校准集、初筛集、确认集及 SHA-256。
5. 只在不属于上述评价集的最多 20 张样本上检查尺寸、概率读取、显存和吞吐；不得读取效果指标选方法。按“样本数 × 每图完整调用成本 × 1.25”估计耗时，超预算则前置失败。
6. 支持集抽样种子固定为 17、29、43；数据划分固定 20261005；bootstrap 固定 104729。随机种子不能因结果差而更换。

冻结前可补充依赖和路径这些事实；本方案的模型、方法、阈值、预算和判定门槛不得在看到任何评价结果后更改。冻结缺项时禁止正式运行。

## 3. 分组与泄漏控制

- 用文件 SHA-256 排除完全重复，64 位感知哈希汉明距离 ≤6 产生疑似近重复对，人工复核合并；阈值先固定。相邻视频帧必须合成同一来源组，不能把帧当独立样本。
- 优先 group_id = 原视频/拍摄事件；其次来源页面或图像系列。来源未知时，相似图保守合组并标记 unknown。不能因“无法证明重复”而默认全部独立。
- 同一 group_id 不能跨支持、校准、初筛、确认。跨数据集也做去重。SAFIRE 的同图多问题必须按 image_id 合并。
- 每个方向所需最小独立组不足，判前置失败，不能用复制帧、数据增强或重采样凑样本。
- 初筛和确认来自预先划开的目标域，确认集只评一次；不把初筛样本并回确认集。目标域标签只供评价，不能选原型、阈值、层或提示词。
- D1/D2 使用 DFire 时划入互斥分区；D1 失败后的图片错误分析不能用于改 D2 固定方法。
- FLAME 来自有限采集活动：即使有大量帧，也不能据此声称已验证许多独立火灾事件。

## 4. 统计与比较

所有候选与基线使用相同输入、支持集、评价组和预处理。先在每个独立组内平均，再跨组宏平均；另给图像级计数和混淆矩阵，避免大视频支配结果。

初筛：只检查预设点估计与安全门槛。确认：重复同一套固定流程，加做 2,000 次分层配对组 bootstrap；火焰/无火焰分别重采样组。方向一先对三个支持种子的指标平均，再重采样评价组，不把种子当新增独立样本。

对“超过所有基线”采用每次 bootstrap 内候选对各基线差值的最小值，取第 5 百分位为单侧 95% 下界，要求 >0。不能从基线中挑一个最弱的比较，也不能挑最好的一次种子。

不因为结果接近门槛增加样本，不追加显著性检验，不在 2,000 次之后改 bootstrap 参数。小样本置信区间偏宽导致失败，是短周期决策的可接受代价。

## 5. 修复例外不能成为调参入口

每方向最多一次技术修复，且计入该方向总预算。只限可由数据格式断言或合成样例重现的程序错误，例如掩码值域颠倒、文件读取失败；修复不能涉及根据评价指标挑参数。

冻结评价已揭示后，如修复改变评价预测且不能证明结果盲态，原确认集已失效，该方向判失败，不重复使用。显存不足只能减小 batch size、保持数值精度与模型不变；仍不可运行就失败。不允许换量化版本、骨干、输入分辨率或数据集继续试。

## 6. 终止动作与论文边界

触发 STOP 时立即停止排队任务，保留已生成日志、预测、环境与校验和，填写终止原因，提交状态；不再调用 GPU。终止报告包括证据、已耗预算和哪些结论尚不能成立。

通过后仅整理现有固定实验、误差案例和写作提纲。不得为“凑论文”补做无上限消融。完整论文仍需审查创新充分性、文献覆盖、评价代表性与目标期刊要求；如现有证据不足，应明确写出不足，而不是自行开启另一轮搜索。
