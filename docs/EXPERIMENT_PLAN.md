# 分阶段实验方案：先证明问题，再证明方法

版本：v1.0（2026-09-18）。工作题目：**匹配可靠性引导的抗配准误差遥感建筑物变化检测**。

## 0. 总目标与边界

目标是形成一篇具有明确问题、实质性方法差异、可复现结果的建筑物变化检测论文，投向单位认可的中科院二区/三区范围期刊。**任何实验门槛都不能保证录用；分区版本、大类/小类、费用和单位认定必须由 G0 单独确认。**

当前只完成路线和辅助工具，不代表课题已通过新颖性审查。LEVIR-CD、S2Looking 和 Open-CD 的来源见 [文献表](RELATED_WORK.md)。公开数据不等于可任意再分发。

算力暂按单卡、256×256 训练裁剪规划；24GB 显存只是规划假设，不是已知设备，也不是运行保证。先测量再决定预算，不预先承诺 GPU 小时或完成日期。

唯一主假设 H1：**在相同数据、增强、训练预算和模型选择规则下，匹配可靠性控制能够减少错位导致的伪变化，且不会以显著损害正常图像或真实变化召回为代价。**

不采用“堆多个模块后看哪个指标提高”的路线。首先在 BIT-R18 上研究；Changer 是已有对齐的强对照，不能被写成无对齐基线。FAEWNet、DC-Mamba 必须进入创新差异审查。

## 1. 如何判定继续、暂停与停止

- **PASS**：该阶段全部硬门槛满足，并有可追溯证据，才能进入下一阶段。
- **HOLD/FIX**：工程或协议问题，停止训练，最多两次有明确原因的修复；记录每次修改。数据污染必须整批作废并重建，不是改一个分数就过关。
- **STOP_PATH**：科学假设不成立、收益不稳定或超过预算，停止当前方法路线。保留负结果，不靠换种子、换测试集或扩大扰动来过关。
- **PIVOT**：只允许一次有新证据的重新立项；重新写假设和协议。不能把同一个失败方法换名字继续烧算力。

所有阈值是项目管理建议，不是文献标准。G0 可以根据设备与可接受误差调整一次；一旦看到候选模型验证结果，就不得为“通过”而降低门槛。协议后续确需改变时，必须编号、说明原因，并把后续实验标为新一轮探索。

**立即停止的红线**：训练/验证/测试图像泄漏；用测试结果选结构、阈值或 checkpoint；错误标签坐标；只报最优种子；把类别平均 mFscore 当变化类 F1；用合成平移成绩宣称解决所有真实配准误差。

## 2. 阶段总览与对总目标的贡献

下列权重是论文证据完成度，不是录用概率，也不是预计耗时比例。阶段交付物完整且 PASS 才计入。

|---|---|---|---:|
| G0 立项审查 | 是否有可区分、可负担的研究问题？ | 文献差异表、预算和投稿认定记录 | 5% |
| G1 环境与数据 | 输入、标签、划分是否可信？ | 环境锁、数据清单、检查报告 | 10% |
| G2 复现基线 | 比较对象是否足够可靠？ | BIT/Changer 基线与计时记录 | 10% |
| G3 问题验证 | 轻微错位是否真有值得解决的损失？ | 基线敏感性曲线、误差归因 | 15% |
| G4 最小方法 | 可靠性机制是否带来独立收益？ | 最小 MR-CD 与公平对照 | 20% |
| G5 机制消融 | 收益是否确实来自所宣称的机制？ | 消融表、可靠性诊断、负例 | 10% |
| G6 第二数据集 | 结论是否只对 LEVIR 有效？ | S2Looking 独立训练/验证结果 | 10% |

## G0：立项、文献差异与资源核验

**动作**：精读 BIT、Changer、至少一个直接错位处理工作以及 FAEWNet/DC-Mamba 的相关部分；进一步检索至执行当日。初始文献表不是完整查新结论。至少整理 8 篇相关论文，其中至少 3 篇最接近本课题。每篇记录：对齐方式、是否保留原始差异、可靠性定义、监督区域、错位协议、代码/权重可用性。判断“已有门控+一致性”是否已经覆盖拟议方法。

写出一个可证伪的差异句：例如“不是仅对齐，而是在不可靠对应处保留真实变化证据，并验证相同增强下的净收益”。若相关工作已经做了同样设计和实验，必须停止或形成新的、有证据的差异。

记录 GPU 型号/显存/驱动、可用存储、可用机时上限、资金上限（如租用）、投稿限制。GPU 未确定不妨碍文献和 CPU 工具检查，但不得直接启动大规模训练。

**PASS**：差异矩阵完整；至少一个尚未被现有方案充分回答、可用实验区分的假设；数据使用条款满足学术用途；单位分区口径及可用预算有记录。

**止损**：投入上限建议 12 个有效研究工时；仍找不到差异，或最接近工作已完整覆盖该假设，STOP_PATH。缺少设备/费用信息属于 HOLD，不构造算力保证。贡献：确定论文问题和边界（5%）。

## G1：环境、数据和标签坐标

**动作**：执行 [起步指南](QUICKSTART.md)。下载作者原始发布的数据，保留原始包校验值；使用作者 train/val/test 划分，先按原始图像划分再裁剪。LEVIR-CD 与 LEVIR-CD+ 不混用。执行 A/B/label 文件匹配、解码、尺寸、标签编码和跨集合重复图像对检查。抽查至少 30 对训练/验证样本，覆盖变化少、变化多、细小建筑、边界模糊和侧视情况。

S2Looking 暂只确认可下载、标签转换和协议可行，不必在本阶段运行大训练；若原包为 Label1/Label2，保留二者并按作者定义构造二值变化并集，检查对应坐标，不把任意非黑色都当变化。转换前后的文件列表与脚本必须版本化。

**PASS**：所有文件可解码且配对一致；未知标签值为 0；跨集合重复图像对为 0（若原始官方划分存在问题，先核验来源并报告，不能静默改官方基准）；单幅复用、近重复和空间重叠人工排查完成；100 个训练 iteration 前向/反向有限值；8–16 个固定训练裁剪关闭随机增强后可过拟合至变化类训练 F1≥95%（最多 1000 iteration，须包含正负像素）。这个 95% 只排查工程，绝不是泛化性能。

**止损**：一旦错把原图 255 正类当 ignore、B 平移时把 Y 同步平移、跨集合先裁剪再随机分配，立即 FIX 并废弃对应结果。环境修复最多两次、建议合计 12 工时；仍失败则切换到作者 BIT 官方实现作环境备选，重新冻结依赖，不在不同实现间直接拼表。贡献：保证结果可解释且可信（10%）。

## G2：建立足够强且可复现的基线

**动作**：先运行 Open-CD 的 BIT-R18，保持官方 256 裁剪、有效 batch=8、40k iteration 和训练策略；先单种子 17。第二个对照是 Changer-R18；其官方常见配置输入/策略可能不同，先复现官方版本，再单独登记用于公平比较的统一协议版本，不能混为同一结果。

训练仅用 train，checkpoint 按未扰动 val 的既定规则选择。默认沿用 Open-CD 的 val mIoU 选模，但论文主要报告变化类 F1；两者不可混淆。记录随机性、全部配置、预训练权重来源与校验值、AMP、有效 batch、采样方式、GPU 时间。

**PASS**：数据/损失/预测可视化一致；验证集变化类 F1≥88% 作为本项目 BIT 开发质量下限；两次评估同一 checkpoint 的确定性结果误差≤0.01 个百分点；不存在全背景输出或明显错误类别映射；训练曲线无 NaN，吞吐和显存实测完成。88% 是初始工程门槛，不是官方验证集指标。

Open-CD BIT 模型表给出的约 90.26 F1 是**测试集**结果，只能在最终相同测试协议下核验，不能拿它直接约束 val，也不能为了凑这个数反复看 test。

**止损**：验证分数不足时只检查数据、预训练、优化器、学习率、batch 和标签，最多两次修复或额外一次完整基线训练；仍不稳定则 HOLD/STOP_PATH，不在坏基线上研究创新。仅因早期 4k 分数偏低不立即判定训练无效。贡献：排除“仅修复了弱基线”的假改进（10%）。

## G3：验证错位问题值得研究

**动作**：对冻结的 BIT 与 Changer 验证集预测，执行 0、1、2、4 像素的固定扰动套件；8 像素仅压力测试，不作为主成功条件。主套件每档 8 个方向，按 Chebyshev 位移半径定义，详见协议。

必须先训练 **BIT+Aug**：在同一训练协议中加入轻微 B-only 错位增强，保留干净样本。它是后续创新方法真正必须击败的对照。对照与创新方法须使用相同增强概率、幅度、有效区域和采样种子策略。

记录正常变化 F1、RF1、未变化像素 FPR、变化召回和边界误差；固定抽样查看至少 30 个错误，区分“错位伪变化”“光照/季节差异”“标注模糊”“真实细小变化漏检”。基于 train/val 抽取至少 100 个可辨识未变化地物对应点估计原始残余错位尺度；无稳定对应点时明确测量局限。

**PASS**：BIT+Aug 仍存在有实际意义的残余问题：主套件相对同一共同区域的 clean F1 平均下降≥3.0 个百分点；或 2/4 像素条件下未变化 FPR 同时增加≥20%相对值且≥0.10 个百分点绝对值，并且真实变化召回未因严重崩溃失去分析意义。另须有 Changer 的敏感性结果，不能故意只挑最弱模型。

**止损**：增强已基本消除问题、只有 8 像素以上才显著出错、或错误主要来自标签而非错位，STOP_PATH。不能逐步放大扰动直到出现漂亮的失败曲线。这里预期的贡献是证明问题存在（15%），不是宣称自己已解决问题。

## G4：最小方法验证，不先堆模块

**建议 v0 结构**：共享 BIT-R18 特征，在单一高分辨率特征层计算局部相关性；从匹配峰值分布和双向匹配残差得到可靠性分数；保留原始差异分支，同时引入可靠性控制的对齐差异分支。原始差异不应被门控完全清空。

首个实现仅用一个局部窗口、一个特征层和一套预先登记的温度/正则，不同时加入边界头、频域模块、额外基础模型和复杂蒸馏。可靠性是启发式分数，未经校准不能称为概率。相关性、双向一致性与门控本身不自动构成创新。

**同台比较**：B0=BIT；B1=BIT+Aug；B2=BIT+Aug+始终对齐；B3=BIT+Aug+等容量普通融合；M=BIT+Aug+可靠性控制。除待研究机制外，数据、初始化、训练步数、增强、checkpoint 选择全部相同。加大网络但没有等容量 B3，不足以支持机制主张。

先跑等预算 10k-iteration 筛选，保留原 40k 学习率日程的相同前缀；最多 4 个候选。短训存在排序偏差，最多允许一个有明确优化证据的候选延长至 40k，与同预算对照比较，不依据 test 延长。

**探索 PASS**：相对 B1，RF1≥+1.0 个百分点、clean F1≥−0.5 个百分点、干净变化召回≥−1.0 个百分点；同时方向上超过 B2/B3。合格候选必须完成正式 40k 确认，不能把短训分数当论文主结果。

**正式 PASS**：相对验证集最强公平控制，RF1≥+1.5 个百分点；clean F1 下降≤0.5 个百分点；干净变化召回下降≤1.0 个百分点；错误分析确有伪变化减少。最强控制由预定的 val 主指标选定，并仍完整报告其他控制。

**止损**：四个候选和一次允许延长后无合格方案，STOP_PATH。若只能通过损害 clean F1>1.0 个百分点获得收益，立即停止该结构；0.5–1.0 区间最多一次明确修复。训练时间或峰值显存比基线增加>25%而收益不到主门槛，停止复杂化。贡献：形成主要方法证据（20%）。

## G5：证明机制，而非仅证明网络变大

**动作**：至少完成 M 去可靠性（常数门控）、门控空间打乱、去双向一致性、去原始差异保留、B2 始终对齐、B3 等容量融合的比较。先用种子17探索，关键 M 对照在 G7 补齐其他种子。

用训练/验证集已知合成位移、未变化标签区域中的对应关系检查匹配误差：高可靠性分位组应有更小端点误差和更少错配。真实变化区通常没有可定义的正确对应，不在那里强制监督真实流场。可比较这一区域门控行为，但不能假设所有变化点的可靠性都必定低。

**PASS**：至少一个与主张直接相关的去组件消融使 RF1 下降≥0.5 个百分点；可靠性分组的匹配误差趋势总体一致；对齐分支没有明显吞掉新增/拆除变化；包含成功、失败及无收益案例。若门控打乱后不变，不能宣称学会了定位可靠区域。

**止损**：消融效果小于随机波动、只增加参数就获得同样结果、或人工挑例才显得有效，撤销机制主张；允许删去无效组件并缩小论文范围一次，不额外增加新模块补故事。贡献：让结论能回答“为什么有效”（10%）。

## G6：在 S2Looking 独立验证

**动作**：用 S2Looking 官方 train/val 独立训练 B1、最强相关控制和 M；初始种子17。固定 G4 后的结构，不为每个数据集另造一个版本。可以按预先登记的通用规则调整训练长度/学习率，但所有对照一致。先跑 10k 筛选再完整训练。

这里是“两个数据集分别训练、分别测试”，不是跨域零样本泛化。直接 LEVIR→S2Looking 可作为预算允许时的附加实验，但必须清楚标注目标域数据是否参与训练/选模，不能混用术语。

**PASS**：S2Looking val 的 RF1 相对最强公平控制≥+1.0 个百分点，clean F1 下降≤0.5 个百分点，变化召回下降≤1.0 个百分点；近似效果在正常侧视样本上具有可解释的表现。

**止损**：一次统一训练设置修复后仍无收益，停止“普遍有效”的投稿主张；可保留 LEVIR 合成鲁棒性研究，但必须重新评估创新与期刊适配，不能默默换多个第二数据集寻找有利结果。真实残余错位无法可靠量化时，仅报告 S2Looking 原生测试表现，不把其全部误差解释为错位。贡献：排除单数据集偶然性（10%）。

## G7：三种子、统计与资源成本

**动作**：在两个数据集上补齐 M、B1、最强对齐/等容量控制的种子17、42、2026。复用已经合规完成的种子17，不重新挑有利结果。控制间使用对应种子，保存逐原图、逐扰动的 TP/FP/FN/TN。

三种子报告均值和样本标准差。以原始图像或可识别独立场景为聚类单位做 2000 次配对 bootstrap；同一原图的所有裁剪与扰动必须一起重采样。种子变异单独报告；不得将像素、24份扰动或相邻裁剪当成独立样本放大显著性。三种子对训练不确定性的估计仍有限。

**PASS**：LEVIR 平均 RF1 增益≥1.5 个百分点、S2Looking≥1.0 个百分点；两个数据集均至少2/3种子为正收益；clean 非劣界限仍满足；配对增益的95%区间下界>0，并明确区间估计条件。小目标/低变化比例子集不能普遍出现明显漏检代价。

同一 GPU、batch1、相同输入与预处理，预热50次，正式计时200次；CUDA同步，报告延迟分位数、峰值显存、参数和训练 GPU 小时。延迟/显存默认增幅≤25%；超出时只能据实报告精度–成本取舍，不能宣称轻量高效。

**止损**：区间跨0或种子不一致时，最多增加预先约定的两个配对种子，只用于减少不确定性，不作为继续寻找显著性的循环。五种子后仍不足则 STOP_PATH/降低主张。不要单凭一个 p 值过关。贡献：稳定性和实际意义证据（10%）。

## G8：冻结之后统一运行最终测试

**冻结清单**：代码 SHA、全部配置、数据清单 hash、结构与超参数、三个种子模型、每个模型的验证集选模规则、阈值、主/次指标、变换列表、比较对象和统计脚本。生成独立冻结记录并提交 Git。

在上述固定条件下，一次完整测试轮次覆盖 LEVIR-CD 和 S2Looking：原生干净全图、主错位共同区域、8像素压力测试、预先定义的轻微仿射/局部平滑形变。最后两类是“未见扰动类型”，不能临时调强度；本仓库当前工具只实现整数平移，仿射/局部形变适配需另写并测试后才能进入冻结清单。

**PASS**：主测试收益方向与 val 一致，主要效果达到事先登记的实际意义水平，clean 非劣界限成立，没有选择性删除种子/方向/子集。若 BIT 的同协议 test 与 Open-CD 参考90.26 F1 相差>1.5个百分点，先核查协议；不直接判创新成功，也不反复用 test 调参追分。

**止损**：测试不支持假设时如实报告，不返回测试集驱动的优化循环。若确认是真实代码错误，写更正记录，所有受影响方法公平重跑；这不等于测试仍完全未见，稿件须披露。贡献：最终外推检验（5%）。

## G9：论文、复现和投稿

**动作**：把主张逐条映射到证据。建议结构：问题与误差分析→可靠性方法→公平实验→消融→第二数据集→统计和限制。不要把“用了注意力/对齐”作为唯一创新。

最低图表集：①方法示意；②错位强度–性能曲线；③两个数据集主结果；④机制消融；⑤三种子与区间；⑥正常/困难/失败案例；⑦计算成本。次要指标不能掩盖主指标失败。

第三方使用干净环境，依照 README 重建基线/核心结果；检查引用、许可、代码依赖、数据入口、匿名投稿要求、真实作者贡献以及单位认可分区。目标期刊可先核验 JSTARS；GRSL/Remote Sensing 等仅作为范围候选，分区与当前要求必须重新确认，不附未经核验的录用概率。

**PASS**：每个核心结论都有公平、可追溯实验；没有把模拟误差夸大为真实全场景能力；代码入口与配置齐全；图表可由结果文件重建；期刊和单位要求已核实。

**止损**：缺少实质差异或结论不被数据支持，不靠换期刊层级掩盖；保存技术报告或负结果，停止继续追加实验。贡献：完成可提交研究产物（5%）。

## 3. 预算控制：按测量值分批释放

定义 T_L：本机一次 BIT-R18/LEVIR 40k 完整训练+固定验证的 GPU 时间；T_S：S2Looking 对应完整预算的 GPU 时间。二者均需实际测量；模型耗时不同应使用真实值计费，不能一律当成相同训练成本。

建议设置以下**上限而非消耗目标**，G0 可按实际资源下调：

| 预算包 | 授权条件 | 上限建议 |
|---|---|---|
| 起步与验证问题 | G0通过后 | 4 T_L（包含工程失败消耗） |
| 方法发现、关键消融、第二集初验 | G3通过后 | 额外8 T_L + 4 T_S |
| 三种子确认、必要复验、最终测试 | G6通过后 | 额外6 T_L + 6 T_S |

总体建议硬上限18 T_L + 10 T_S；若按实际实验矩阵测算超限，先缩减非关键候选，不删去 Aug/对齐/等容量控制、第二数据集或主结果复验。测试24种扰动会增加推理成本，需显式计入余量。预算耗尽而证据不足则停止，不自动追加。

经济成本 = 各设备实际计费GPU小时×各自单价 + 存储/流量费用。禁止凭未测 GPU 型号预估一个看似精确的总价。当前环境无CUDA，本方案没有实测 T_L/T_S。

## 4. 实验台账与每日工作方式

每次启动前在 `experiments/registry.csv` 登记 run_id、假设、配置、代码、数据清单、seed 和预算。失败/中止任务也登记。结束后追加结果、GPU小时、错误原因、是否支持假设。

每个 Gate 复制 `experiments/GATE_TEMPLATE.md`，提交“证据→判定→下一步”，而不是只打钩。任何 STOP_PATH 都保留最后一个可复现 checkpoint 的私有存储位置和 hash，公开仓库不上传权重或原始数据。

当前第一步是 G0 和 G1。**不要在基线和错位诊断过关前实现完整创新网络。**
