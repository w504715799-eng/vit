# 预注册评价与实现协议

版本v1.0；所有数值为本项目初始设计，不是领域统一标准。G0可修改并冻结；看到候选模型结果后修改应另记探索版本。

## 1. 数据边界与坐标系

每个样本为(A,B,Y)。A是参考图像，Y定义在A的原始坐标系。模拟错位只扰动B：`B'(x,y)=B(x-dx,y-dy)`，正dx向右、正dy向下。A和Y不平移。这个任务目标是恢复参考坐标下原有变化图，不是对错位后像素值差异重新标注。

源标签0/255中的255是变化正类。先显式转换为0/1；如框架用255表示ignore，必须在转换之后另行引入ignore。工具函数不猜测255的语义。

按作者原图split划分，再产生训练裁剪；验证/测试推理裁剪必须拼回原图统计。禁止来自同一原图的patch跨split。测试集只做结构完整性审查，不作为开发误差分析来源。

LEVIR为主数据集，S2Looking独立训练/测试为第二数据集。后者并不自动证明跨域泛化。原生数据中的视差、光照和配准误差应分开讨论。

## 2. 扰动套件

主套件采用`s={1,2,4}`，每个s有8方向：

```text
(s,0), (-s,0), (0,s), (0,-s), (s,s), (s,-s), (-s,s), (-s,-s)
```

这里s是最大轴位移（Chebyshev半径），对角线欧氏位移为sqrt(2)*s；不能把两者混称同一欧氏位移。像素以原始输入分辨率计，不能混为特征图像素。先在原图B生成扰动，再按统一推理pipeline处理；任何resize对应的像素尺度须记录。

同时报告s=0的原生clean结果。所有主套件条件（包括它们的clean对照）使用**同一个四边4像素内缩区域**。这防止不同扰动丢弃不同像素而导致分数不可比。另报未裁边的官方clean全图指标，不把它与裁边扰动分数直接相减。

不得用`np.roll`制造环绕像素。平移外部填0，但其区域不参加loss/指标。训练的ignore与padding区域需核验；mask不作为模型额外输入。当前工具提供整数平移与共同mask，不包含完整框架适配。

s=8作为压力测试，使用8像素共同内缩及重新计算的同区域clean对照，单独成表，不纳入主RF1。

次要泛化套件预定为：绕图像中心±0.5度旋转；以及seed=2026生成的局部平滑位移场（4×4控制点网格双三次上采样，最大轴位移归一化到2像素）。必须记录采样方向、插值、归一化和完整代码，使用所有条件warp-valid-mask的共同交集。标签仍在A坐标，不随B变换。套件实现及单元测试完成后才能冻结，不能把这段设计当成已实现功能。

## 3. 训练扰动与公平性

初始Aug方案：每对样本50%保持相对几何不变，50%只扰动B；s在1/2/4中均匀抽样、方向在上述8方向均匀抽样。随后对A/B/Y执行相同裁剪/翻转；只扰动B的动作不能误施加给Y。所有候选和Aug控制使用同一分布、相同ignore规则与增强预算。

主方法也必须与原始无增强B0比较，但成功标准是超过B1=同等Aug，而不是仅超过B0。对齐控制、等容量融合控制不能省略。

固定数据划分、预训练来源、训练日程、实际有效batch、损失权重、AMP、输入分辨率和checkpoint规则。结构改变引起的额外参数/训练时间应公开。缩短pilot只截取同一40k学习率日程前缀，不能给不同候选不公平地加速学习率衰减。

## 4. 主次指标与计算顺序

以变化为正类。每个固定扰动条件下先对全部原始图像汇总TP、FP、FN、TN，再算：

```text
F1 = 2TP / (2TP + FP + FN)
IoU = TP / (TP + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
Unchanged-FPR = FP / (FP + TN)
RF1 = mean_s(mean_direction(F1_s,direction)), s in {1,2,4}
```

RF1是24个固定条件的等权平均，不是24组计数合并后算一次F1，也不是只选最佳方向。完整报告每档每方向和最差条件，避免均值掩盖极端失败。

所有代码/CSV率值用0..1存储；文章显示百分数。`+1.5个百分点=+0.015`，不是相对提升1.5%。变化类F1不等于包括背景的mFscore。

分母为0时保存null；不得把无变化且无预测图像的F1强制设1，再进行逐图平均。主要F1使用全数据micro聚合，纯背景组主要看FPR/错误面积。

次要指标：IoU、Precision/Recall、边界F1（2像素容差，先冻结边界提取规则）、小变化连通域召回和延迟/显存。只有二值变化标注时，连通域未必一一对应真实建筑实例；不要把连通域指标描述为严格实例级检测精度。次要指标不能替代主RF1或clean非劣检验。

## 5. 最小方法的接口与防投机约束

建议第一版仅在stride=4特征层使用局部5×5窗口相关性（radius=2），先L2归一化再softmax，温度初值0.1。匹配熵可给出峰值可靠性：`r_peak=1-H(p)/log(25)`。双向对应残差可形成`r_cycle=exp(-e/tau)`，tau初值1个特征像素。

拟议门控`g=clip(r_peak*r_cycle,0,1)`用于调节对齐差异分支，同时保留未经对齐的差异分支：例如`concat(D_raw, g*D_aligned)`再用统一融合头。不能只输出对齐后的差异并抹除原始证据。上述数值是首个实验候选，不是已验证最优参数，不是原创性证明。

如果使用双向流，A→B映射和B→A映射必须在对应采样点比较，而不是在相同下标直接相加。至少用已知整数平移的合成特征验证方向和像素单位。特征stride与输入位移换算、grid_sample的归一化、align_corners设定必须统一并写入配置。

第一版不额外叠加多任务损失。如果后续引入几何约束，只在train中已知未变化且有效的区域施加，并适当排除变化边界；真实变化区域不应被强制对齐。验证/测试绝不允许读取Y来产生g、估计位移或选择变换。Y仅供离线评分和诊断。

必须测试退化模式：g恒0、g恒1、空间打乱g、去循环一致性、去原始差异、同参数量普通融合。高可靠性应能预测更好的匹配，而不是仅仅预测背景比例。

## 6. checkpoint与阈值

基线与候选均使用未扰动val、相同规则选checkpoint；初始沿用Open-CD val mIoU。每个种子只产生一个被选模型用于所有扰动，不能按扰动各选不同checkpoint。

二分类双logit使用argmax；单logit使用0.5，默认不额外搜索阈值。若确需校准，所有方法同预算，仅在val完成并对所有扰动固定阈值；变更须发生在冻结前。

不得用test早停、挑种子、选结构、调位移范围或调误差容差。模型选择、协议和主要对照在G8前提交Git冻结。

## 7. 重复、置信区间与资源

主模型及关键控制使用17、42、2026三个种子。在每个种子、每个原图上保存完整24条件计数。配对bootstrap时重采样原图/独立场景，并同时保留其全部条件和配对模型结果；重新计算micro F1和RF1差，不把像素作为独立样本。

建议2000次重采样，给出2.5%和97.5%分位点；可以对固定种子组的平均差做场景bootstrap，但必须说明该区间主要刻画样本变异。训练seed标准差单独报告；三个seed不能充分刻画所有训练不确定性。若补充两个seed是看过结果后的决定，应披露顺序，不将其包装为未经选择的固定显著性检验。

主要比较为M对预先按val选定的最强公平控制；其他控制与子集结果全部透明列出。test仍承担冻结后确认的职责。若有可用地理组信息，优先按区域聚类；只有原图ID时说明残余空间相关性限制。

统一GPU/驱动/输入分辨率/batch1/精度模式，预热50次、计时200次，CUDA同步，报告中位数与P95。分别列模型前向和包括预处理的端到端耗时，不能把两种口径混比。
