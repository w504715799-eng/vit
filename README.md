## 研究问题

当第二时相图像发生轻微错位时，能否利用局部匹配的可靠性减少伪变化，并避免把真实新增/拆除建筑物“对齐掉”？

主数据集：LEVIR-CD。第二数据集：S2Looking。开发底座：Open-CD 的 BIT-R18；已有对齐方法 Changer 必须作为对照，而不能被误当作无对齐基线。

拟议方法简称 MR-CD，仅为工作名。局部相关性、双向一致性和门控融合都有已有研究基础；必须通过文献差异表和消融实验确认本项目的真实贡献。

## 最重要的停止规则

- 数据泄漏、标签坐标错误、测试集调参：立即停止并修复；污染结果不得使用。
- 2–4 像素错位没有造成可重复、值得解决的损失：停止“抗错位”主线，不通过放大到不现实的扰动制造问题。
- 最小方法不能超过同等增强的基线，或正常图像 F1 明显退化：停止加模块。
- 第二数据集不支持结论：降低结论范围或停止当前投稿主张，不不断更换数据集寻找正结果。
- 所有提升门槛均为预先提出的工程决策值，不是行业统一标准，不代表二区/三区录用概率。

## 基础工具

`tools/preflight.py`：环境报告和 A/B/label 数据完整性检查；不会训练模型。

`tools/protocol_utils.py`：无环绕整数平移、共同有效区域、二分类计数指标。

`tests/test_protocol.py`：合成数组单元测试；通过不代表通过真实数据训练验证。

```bash
python -m pip install -r requirements-tools.txt
python -m unittest discover -s tests -v
python tools/preflight.py doctor --out reports/environment.json
```

完整 CUDA / Open-CD 环境安装见起步指南；上述轻量工具无需先安装 PyTorch。
