# 论文与研究资料库

用于论文编写、文献整理、实验记录和研究资料的版本管理与备份。

## 目录

| 目录 | 内容 |
| --- | --- |
| `manuscript/` | 论文正文、提纲、投稿材料和定稿 |
| `references/` | 文献索引、BibTeX 条目和阅读笔记 |
| `experiments/` | 实验设计、参数、结果摘要和复现记录 |
| `notes/` | 研究日志、想法、讨论与待办 |
| `figures/` | 论文插图、图表及可编辑源文件 |
| `code/` | 数据分析、制图和实验辅助代码 |
| `data/` | 数据来源、目录索引和获取说明 |

## 日常保存

1. 将材料放入对应目录；同一论文可以在各目录下用相同项目名组织。
2. 每次完成一段正文、一篇阅读笔记或一组实验，检查并提交改动。
3. 推送到 GitHub 后，本次提交才完成远端备份；本仓库没有配置自动同步。

```bash
git pull --ff-only
git status
git add <本次需要备份的文件或目录>
git diff --cached
git commit -m "docs: 更新论文与研究记录"
git push origin main
```

PDF、Word 文档、图片和 BibTeX 文件均可纳入版本管理。临时文件和编译产物由 `.gitignore` 排除。大型数据集与模型权重保存在独立存储，并在 `data/` 记录位置、版本及校验信息。
